This document outlines contribution guidelines for the Pokemon GBA Archipelago suite of projects created by me (Flit),
including Pokemon Emerald Version (Flit's ver.) and the Pokemon GBA Combo Randomizer.

## Pull request guidelines

For feature implementations, please [discuss](#communication) what you'd like to contribute with me before making a
pull request. I have a specific vision for these projects, and I'd rather not have to close or heavily modify your pull
request just because it conflicts with that vision.

Bug fixes are always welcome and encouraged!

> [!NOTE]
> The rest of these PR guidelines aren't in effect yet. They will go into effect starting with the release of version 1.0.0.

To ensure cleanliness, PRs must use the PR template.

Additionally, PRs must pass all tests. These tests are as follows:

- **Fuzz APWorld:** Runs the [Archipelago fuzzer](https://github.com/Eijebong/Archipelago-fuzzer).
No failures should occur. Ignored results are fine.

## AI usage

In this section, "AI", "GenAI", and "LLM" refer to generative artificial intelligence tools,
including Large Language Models and similar technologies.

**All contributions are expected to be made by humans, with ZERO AI assistance.**
You may use AI tools for research and learning (I cannot realistically enforce restricting this),
but all content in submitted contributions must originate from and be understood by you, the contributor.

This includes, and is not limited to:

- Code
- Artwork, and other visual assets
- Documentation
- Titles and description text for GitHub Issues, PRs, discussion posts, and commits
- Comments on issues, PRs, commits, and discussion posts in all discussion spaces related to the project,
both on and off of GitHub
- Security reports

This notably prohibits, among other uses:

- AI review tools in pull requests
- AI-generated change summaries in issues and pull requests
- Bug and security reports generated by AI tools

Any use of GenAI tools will result in your issues/PRs being closed, any code you contributed being removed or rewritten,
and/or you receiving a ban from the project's repositories and potentially other community spaces I manage.
