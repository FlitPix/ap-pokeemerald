# Pokémon Emerald Version AP (Flit's ver.)

This is my take on an [Archipelago](https://archipelago.gg) randomizer implementation for [Pokémon Emerald Version](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9mon_Emerald_Version).

## How to play

Players can refer to the [game page](</docs/en_Pokemon Emerald Version - Flit's ver..md>), then the [setup guide](/docs/setup_en.md).

## AI Disclosure

I don't use GenAI at all whatsoever in the development of Pokémon Emerald Version (Flit's ver.). Furthermore, contributions
written using GenAI are not accepted; see [`CONTRIBUTING.md`](/CONTRIBUTING.md) for more information.

Some code was copied from or based off of the implementations for Pokémon Emerald (core), Pokémon FRLG, and Pokémon Crystal.

- It is not yet confirmed whether Pokémon Emerald Archipelago (core) has used GenAI in its development.
	- The project's code has existed since before the advent of GenAI.
	- Note that the overall Archipelago project *has* used GenAI for both code and documentation, with no overall disclosure,
    and the longer-term community members either tolerate or embrace it.
- Pokémon FRLG Archipelago has been [confirmed in the official Archipelago Discord server](<https://discord.com/channels/731205301247803413/1365127226533871718/1365471650543566990>)
to not use GenAI.
- Pokémon Crystal Archipelago has been [confirmed in the official Archipelago Discord server](<https://discord.com/channels/731205301247803413/1365127145709502575/1518655593651376379>)
to use GenAI for code, but not art or other visuals.

This disclosure, in its entirety, applies to both the APWorlds and basepatch.
