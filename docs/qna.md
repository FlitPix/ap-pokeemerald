# Q&A for Pokemon Emerald Version Archipelago (Flit's ver.)

## Generation and options

### As the host, do I need the ROM to generate a multiworld with this game?

No.

## Gameplay

### What's the difference between this APWorld and the one that comes with Archipelago? Which should I play?

Zunawe's Pokemon Emerald implementation - the one that comes with Archipelago - has existed for much longer and is
significantly more stable, but does not receive frequent feature updates.

Pokemon Emerald Version Archipelago (Flit's ver.) is newer and less stable. However, many new features are planned as well,
such as parity with other Pokemon implementations and new ideas that take further advantage of the game's exclusive features
and its decompilation.

Playing either APWorld is valid. I recommend trying both and seeing which you prefer.

### Where do I go next?

Please play the vanilla game.

If you need a walkthrough, [this one might help](https://bulbapedia.bulbagarden.net/wiki/Walkthrough:Pok%C3%A9mon_Emerald).

### How do I traverse these obstacles?

[Muddy slopes](https://bulbapedia.bulbagarden.net/wiki/Bike_obstacles#Muddy_slopes)
can be ridden up using the Mach Bike at high speeds.

[Rails](https://bulbapedia.bulbagarden.net/wiki/Bike_obstacles#Rails_and_logs) require the Acro Bike.
Press a direction and B at the same time to [hop sideways](https://archives.bulbagarden.net/wiki/File:SidewaysHop.png)
or do a 180.

[Bumpy slopes](https://bulbapedia.bulbagarden.net/wiki/Bike_obstacles#Bumpy_slopes) require the Acro Bike.
Hold B to [bunny-hop](https://archives.bulbagarden.net/wiki/File:LedgeE.png). You can move while bunny-hopping.
Bunny-hopping also can cause encounters with wild Pokemon.

### Is a PopTracker pack planned?

No, but I am open to the community creating one if they wish.

## Development

### Is this unsafe / a virus / malware?

While it's good to ask this question, asking the person who would have potentially made a virus, if it is a virus,
is not smart. What's stopping them from saying no? Would you just believe them? Why?

This project is open source. If you're concerned about downloading unsafe code, you can vet the code for yourself.
The APWorld source can be found [here](https://github.com/FlitPix/ap-pokeemerald).
The basepatch source can be found [here](https://github.com/FlitPix/pokeemerald).
